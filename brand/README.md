# SuperImg brand

## Concept

**Layered frames + play** — “layer the frame, direct the motion.”

Three stacked cards (composition layers) with a play wedge on the front layer (render/motion). Palette matches existing SuperImg sample gradients: indigo → violet (`#667eea` → `#8b5cf6` / `#a855f7`) on deep ink (`#0b0b14`).

## Files

| File | Use |
|------|-----|
| `superimg-mark.svg` | App icon / social avatar (128 viewBox, rounded tile) |
| `superimg-mark-flat.svg` | Favicon / small UI (32 viewBox, no filters) |
| `superimg-logo.svg` | Horizontal lockup on dark backgrounds |
| `superimg-logo-light.svg` | Horizontal lockup on light backgrounds |

## Wordmark

- Product name: **SuperImg** (capital I)
- Lockup: `Super` in foreground gray/ink · `Img` in violet accent
