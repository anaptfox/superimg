# Admission

Three separate decisions. Do not collapse them into "text versus image."

| Decision | Examples |
|---|---|
| What information is represented? | Exact values, appearance, time, dependencies, possible outcomes |
| What work should the reader perform? | Retrieve, recognize, compare, diagnose, evaluate, remember, act |
| How is it delivered? | Native text, table, interactive, image, recording |

A typeset paragraph exported as PNG is still a paragraph. A table already uses
spatial alignment. Genuine styled text is not the same as an image of text.

## The test

Not "could this be verbalized."

**Does verbalizing it transfer useful work back into the reader's head?**

A timetable and a paragraph can name the same appointments. Only one makes
collisions easy to find.

Accessibility is a second path to the same information, not an argument against
the visual. Complex charts need structured data or a longer explanation, not
only a one-sentence caption.

## Defaults for a question (not laws)

Same measurements, different questions:

| Reader's question | Default |
|---|---|
| What was the exact p95? | Labeled number |
| Which regions regressed? | Ordered comparison |
| Did they regress at the same time? | Aligned intervals or aligned series |
| What value goes in the incident report? | Copyable text with source |

A chart earns its place when the person must inspect a pattern, assess the
answer, explore alternatives, or make a judgment a scalar does not settle.

## Name the work

"Looks clearer" is not an admission.

"The reader no longer has to remember three start times while checking three
end times" is.

An image can be dense and still externalize nothing. A large BUILD PASSED tile
does not remove work the sentence "Build passed" required.

## Complete interaction

Evaluate **notice → understand → inspect → respond or act**.

A picture that helps the first two and wrecks the last two is a net loss.

Addressability: "the spacing at marker B differs from the reference" is
actionable. "This looks wrong" is not. Stable ids, source, and version belong
in the arrangement.

Memorability and immediate analysis are different outcomes. Aesthetic or
commemorative pictures are allowed when those are the actual job — they must
not masquerade as analytical instruments.
