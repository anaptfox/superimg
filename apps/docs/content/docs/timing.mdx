# Timing With Director And Tracks

SuperImg has two timing primitives for most template work:

- `ctx.director()` choreographs scene-local phases from `timeline.progress`.
- `ctx.track()` follows absolute transcript or marker timestamps using `timeline.seconds`.

Use the director when the scene owns timing. Use a track when external narration or marker data owns timing.

## Enter, Hold, Exit

```typescript
render(ctx) {
  const t = ctx.director();
  const card = t.motion({ y: 32, scale: 0.96 });
  const eyebrow = t.motion({ at: "15%", y: 20 });
  const number = t.tween(0, 1280, { during: "enter", at: "20%" });

  return Frame(
    { motion: card, pad: 32, radius: 20, fill: "#151923" },
    Stack(
      { gap: 12 },
      Text({ variant: "label", motion: eyebrow }, "Downloads"),
      Text({ variant: "display" }, Math.floor(number).toLocaleString()),
    ),
  );
}
```

## Named Phases

Phase values are explicit percentages or durations.

```typescript
render(ctx) {
  const t = ctx.director({
    intro: "18%",
    terminal: "62%",
    summary: "12%",
    outro: "8%",
  });

  const shell = t.motion({ during: "intro", y: 28, exit: false });
  const commandProgress = t.in("terminal");
  const summary = t.motion({ during: "summary", y: 18 });
  const fade = t.tween(1, 0, { during: "outro", easing: "easeInCubic" });

  return Frame(
    { motion: shell, style: { opacity: shell.opacity * fade } },
    Stack(
      { gap: 16 },
      Text({ variant: "body", fontFamily: "ui-monospace" }, commandProgress > 0.5 ? "build complete" : "npm run build"),
      Text({ variant: "body", motion: summary }, "Ready to ship"),
    ),
  );
}
```

`t.active` identifies the current phase. `t.in("phase")` returns progress scoped to that phase.

## Nested Clips

`t.clip()` opens a nested timing window with its own local director.

```typescript
render(ctx) {
  const { std, width, height, data } = ctx;
  const t = ctx.director({ hook: "2s", demo: "3s", outro: "1s" });
  const hook = t.clip({ during: "hook" });

  if (hook.active) {
    const local = hook.director();
    const card = local.motion({ y: 32, scale: 0.92 });
    return Frame(
      { width, height },
      Stack(
        { width: "fill", height: "fill", align: "center", justify: "center" },
        Text({ variant: "display", motion: card }, data.hook),
      ),
    );
  }

  // ...demo and outro clips
}
```

## Transcript Timing

Convert provider data outside the render loop, then pass normalized word timings to `ctx.track()`.

```typescript
import { fromElevenLabs } from "@foxworth/superimg/transcript";

const words = fromElevenLabs(rawTranscript);
```

```typescript
render(ctx) {
  const transcript = ctx.track({ id: "voiceover", words: ctx.data.words }).transcript();
  const current = transcript.current();

  return Vector(
    { id: "captions", width: ctx.width, height: 120 },
    vector.text(
      { id: current?.id ?? "caption", x: 40, y: 76, size: 48, fill: "white" },
      ...transcript.map((word) =>
        vector.run(
          { fill: word.active ? ctx.data.accentColor : "white" },
          `${word.text} `,
        ),
      ),
    ),
  );
}
```

## Marker Timing

```typescript
const markers = ctx.track({
  id: "story-beats",
  markers: { intro: 0, demo: 2.5, cta: 8 },
}).markers();

const demoProgress = markers.progress("demo", "cta");
const demo = markers.segment("demo", "cta");
```

Stable track IDs are recommended and required when compiling strict Media IR.

## Combining Them

Use the director for the frame and a track for narration-synced content inside it.

```typescript
render(ctx) {
  const { std, data } = ctx;
  const scene = ctx.director({ enter: "12%", captions: "76%", exit: "12%" });
  const panel = scene.motion({ y: 24 });

  const transcript = ctx.track({ id: "voiceover", words: data.words }).transcript();
  const phrase = transcript.between(0, 3);
  const opacity = std.interpolate(phrase.progress, [0, 1], [0.25, 1], "easeOutCubic");

  return Frame(
    { motion: panel },
    Text({ variant: "title", style: { opacity } }, phrase.text),
  );
}
```
