# What is SuperImg?

Write a media program once — play it live, export it anywhere. One TypeScript program can power a product Player and platform-ready files without duplicating content.

```text
video/image/svg/ogImage
          ├── Player (live)
          └── export --for … (files)
```

Start by authoring with helpers and the layout tree. Drop to `define()` when you need an unusual clock or media contract.

```ts
import { video, Frame, Stack, Text } from "@foxworth/superimg";

export default video({
  duration: "8s",
  render(ctx) {
    const t = ctx.director({ enter: "15%", hold: "70%", exit: "15%" });
    return Frame(
      { width: "fill", height: "fill" },
      Stack(
        { width: "fill", height: "fill", align: "center", justify: "center" },
        Text({ variant: "display", motion: t.motion({ y: 24 }) }, "Hello"),
      ),
    );
  },
});
```

SuperImg separates three jobs:

- Media defines content, timing, and responsive behavior.
- Collections define batch data sources.
- Destinations define delivery canvases and encoders at export time.

Docs follow the same doors: **Author** (default), **Embed** (same program in an app), **Extend** (server, adapters, hosts). Interactive media is a singular live-data path imported from `@foxworth/superimg/interactive/define`. Neutral media and the passive Player do not expose guides, actions, or scene navigation.
