# CLI Reference

## Core workflow

```bash
superimg list
superimg setup
superimg doctor --json
superimg dev launch.media.ts
superimg check launch.media.ts
superimg inspect launch.media.ts
superimg export launch.media.ts --for youtube
superimg plate subject.mp4
```

`setup` installs Chromium headless shell into the account Playwright cache (or `SUPERIMG_BROWSERS_PATH`). `doctor --json` reports `CHROMIUM_OK`, `CHROMIUM_MISSING` (run setup), or `CHROMIUM_LAUNCH_DENIED` (binary present, launch failed — do not re-setup). `list` and discovery do not execute collection providers. `dev` and `inspect` resolve a collection once and select its first entry unless `--entry` is supplied. `check` validates every entry; repeat `--entry` to restrict it. `export` materializes every entry unless restricted.

## Export destinations

```bash
superimg export launch --for youtube --for instagram-square
superimg export launch --for 1080x1920.mp4 --for 1200x630.png
```

`--for` is repeatable and accepts a destination id or `WIDTHxHEIGHT[.format]`.

Organic destination ids:

```text
youtube  instagram-square  tiktok  linkedin  facebook
x        pinterest         threads reddit
```

## Collections and variants

```bash
superimg check episodes
superimg check episodes --entry introduction --entry architecture
superimg export episodes --for youtube
superimg export episodes --entry introduction --for youtube
superimg export cards --variant dark --for instagram-square
```

`--entry` on ordinary or interactive media fails. Providers execute once per command snapshot, before rendition planning.

## Still selection

Animated media requires an explicit poster declaration or export time when targeting a still format:

```bash
superimg export launch --for 1200x630.png --at 2.5s
```

Exports use full preflight and atomic bundle publication. A failed command preserves the last-known-good bundle.

```text
output/episodes.export/
  export.json
  media/
    introduction/youtube.mp4
    architecture/youtube.mp4
```

The manifest records entry ids and data digests, never raw entry objects.
