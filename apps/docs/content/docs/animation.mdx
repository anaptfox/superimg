# Animation Basics

SuperImg animation is a **pure function of scene time**. The browser Player and headless renderer call `render(ctx)` for each frame, so use `timeline.progress` or `timeline.seconds` instead of wall-clock state.

Use `ctx.director()` when motion belongs to named scene phases. Use `std.interpolate()` when you already have progress and need custom ranges, loops, or multi-keyframes.

## The Mental Model

Instead of “animate opacity from 0 to 1,” ask: **what is the opacity at this frame?**

```typescript
render(ctx) {
  const { timeline, std } = ctx;
  const fade = Math.min(1, timeline.seconds / 1);
  const opacity = std.interpolate(fade, [0, 1], [0, 1], "easeOutCubic");

  return Text({ style: { opacity } }, "Hello");
}
```

## Sequenced Animation With `ctx.director()`

Phase values use explicit percentages or time units. Motion offsets use `at` and `for`, also with units.

```typescript
render(ctx) {
  const t = ctx.director({ enter: "25%", hold: "50%", exit: "25%" });

  const title = t.motion({ y: 20 });
  const body = t.motion({ at: "30%", for: "60%", y: 12 });

  return Stack(
    { gap: 16 },
    Text({ variant: "display", motion: title }, "Title"),
    Text({ variant: "body", motion: body }, "Body"),
  );
}
```

`ctx.director()` handles entrance and exit progress automatically.

### Common Motion Options

| Option | Description |
|---|---|
| `x`, `y`, `scale`, `rotate`, `blur` | Starting pose for the entrance |
| `fromOpacity` | Starting opacity |
| `during` | Named phase to use |
| `at` | Offset inside the phase, such as `"120ms"` or `"20%"` |
| `for` | Motion window, such as `"350ms"` or `"60%"` |
| `easing` | Easing, semantic motion name, spring preset, or spring config |
| `exit` | `false` to hold, or a partial motion for a custom exit |

## Easing And Springs

Named easing curves work in `t.motion()`, `t.tween()`, and `std.interpolate()`:

```typescript
const title = t.motion({ y: 24, easing: "easeOutCubic" });
const overshoot = t.motion({ scale: 0.92, easing: "easeOutBack" });
```

Director motion also accepts spring presets: `gentle`, `snappy`, `fluid`, `playful`, and `wobbly`.

```typescript
const pop = t.motion({ scale: 0.9, easing: "playful" });
const scale = std.spring(0.8, 1, timeline.progress, "gentle");
```

Use an explicit config when you need it:

```typescript
const x = std.spring(0, 500, timeline.progress, {
  stiffness: 200,
  damping: 20,
  mass: 1,
});
```

## Multi-Keyframe Interpolation

`std.interpolate()` takes numeric progress, paired input/output ranges, and an optional easing name or function.

```typescript
const opacity = std.interpolate(
  timeline.progress,
  [0, 0.2, 0.8, 1],
  [0, 1, 1, 0],
);

const x = std.interpolate(
  timeline.progress,
  [0, 0.5, 1],
  [0, 500, 300],
  "easeInOutCubic",
);

const bg = std.interpolateColor(
  timeline.progress,
  [0, 0.5, 1],
  ["#0f172a", "#1e1b4b", "#0f172a"],
);
```

## Staggered Collections

Pass the collection and a numeric progress value to `std.stagger()`:

```typescript
render(ctx) {
  const { timeline, std } = ctx;
  const items = std.stagger(
    ["First", "Second", "Third"],
    timeline.progress,
    { duration: 0.4, easing: "easeOutCubic" },
  );

  return Stack(
    { gap: 12 },
    ...items.map(({ item, progress }) => {
      const y = std.interpolate(progress, [0, 1], [20, 0]);
      return Text({ style: { opacity: progress, transform: `translateY(${y}px)` } }, item);
    }),
  );
}
```

For chat, FAQ, or other accumulating lists, prefer `std.stack()`. For one-at-a-time replacement, use `std.carousel()`.

## Looping Animation

```typescript
const cycle = (timeline.seconds % 2) / 2;
const scale = std.interpolate(cycle, [0, 0.5, 1], [1, 1.1, 1], "easeInOutSine");
```
