# Getting Started

Author a media program, check it, then export for destinations — or embed the same program with the Player.

## Install

The CLI requires Node.js 24.21.0 or newer. If you only need the core library
on Node.js, its minimum is 22.12.0.

```bash
npm i @foxworth/superimg
npm i -D @foxworth/superimg-cli
npx superimg setup
npx superimg doctor --json
```

One-off CLI use without a project install is `npx @foxworth/superimg-cli <cmd>`. With `@foxworth/superimg-cli` installed, keep using `npx superimg <cmd>`.

`setup` downloads Chromium headless shell once into the account Playwright cache (`~/Library/Caches/ms-playwright` on macOS, `~/.cache/ms-playwright` on Linux). Override with `SUPERIMG_BROWSERS_PATH`. Run `setup` again only when doctor reports `CHROMIUM_MISSING`. `CHROMIUM_LAUNCH_DENIED` means the binary is present but could not start — do not re-download.

## Make a video

```ts
import { video, Frame, Stack, Text } from "@foxworth/superimg";

export default video({
  duration: "6s",
  sample: { title: "Ship it" },
  render(ctx) {
    const enter = ctx.director({ enter: "20%", hold: "80%" });
    return Frame(
      { width: "fill", height: "fill", fill: "#0b1020" },
      Stack(
        { width: "fill", height: "fill", align: "center", justify: "center" },
        Text(
          { variant: "display", color: "#fff", motion: enter.motion({ y: 24 }) },
          ctx.data.title,
        ),
      ),
    );
  },
});
```

`video()` defaults to 1920×1080, 30 fps, and MP4. Use `image()`, `svg()`, or `ogImage()` for still, vector, and 1200×630 Open Graph media.

`render(ctx)` returns a typed tree. Use `Frame` for positioned boxes, `Stack` for
flow layout, `Text` for typography, and `Vector` plus `vector.*` for inspectable
SVG geometry. Box deliberately opaque third-party markup with `Html()`.

## Check, then export

```bash
npx superimg check hello.media.ts
npx superimg export hello.media.ts --for youtube
npx superimg export hello.media.ts --for instagram-square --for 1440x1440.mp4
npx superimg dev hello.media.ts
```

The media program owns content and responsive layout. `--for` owns the delivery canvas and encoding. Custom targets use `WIDTHxHEIGHT[.format]`. Embed the same program with the [Player](/docs/player) when you need it live in an app.

## Batch materialization

Collections run one deterministic media program against many entries:

```ts
import { collection, image, Frame, Stack, Text } from "@foxworth/superimg";

interface Product { id: string; name: string }

export default collection({
  entries: [
    { id: "camera", name: "Camera" },
    { id: "tripod", name: "Tripod" },
  ],
  media: image<Product>({
    render: (ctx) => Frame(
      { width: "fill", height: "fill", fill: "#f6f3ec" },
      Stack(
        { width: "fill", height: "fill", align: "center", justify: "center" },
        Text({ variant: "display" }, ctx.data.name),
      ),
    ),
  }),
});
```

Use a zero-argument provider imported from a dedicated server module when entries come from a database or API. Provider code and raw entry data do not enter browser bundles.
