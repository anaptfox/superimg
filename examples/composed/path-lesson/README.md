# Branching path lesson

Both routes share the question and closing. The beginner explanation lasts 40
frames, while the advanced route lasts 80, so the closing begins at frame 65 or
105 respectively. A timed export names the selected route explicitly. The
browser host lets a viewer choose a route and records it in the URL.

`path-lesson.media.ts` exports the beginner route. `routes/advanced.media.ts`
exports the advanced route from the same Program.
