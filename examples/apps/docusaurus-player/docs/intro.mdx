# SuperImg in Docusaurus

This example embeds **SuperImg** `<Player>` previews **inside MDX documentation** — as inline explainers next to prose, not as a homepage hero video.

## What you get

- **Inline explainers** — `DocExplainer` pairs copy with a compact hover-to-play loop
- **Zero-config preview** — `import { Player } from "superimg/react"` with no Vite/Webpack aliases
- **SSR-safe** — `SuperImgPlayer` wraps `@docusaurus/BrowserOnly`
- **Preview-only** — no export/compile graph in this docs site

## Quick start

```bash
# From monorepo root
just install
cd examples/apps/docusaurus-player && pnpm install && pnpm dev
```

Open [http://localhost:3005/docs/explainer](http://localhost:3005/docs/explainer).
