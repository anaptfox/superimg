# Path Lesson Scroll

This host fixes one explicit lesson route in the URL and connects the selected
projection to the Player's scroll drive. Scroll through the pinned canvas to
seek that route's timeline; switching Beginner or Advanced builds a fresh
projection and keeps scroll as the driver.

Open `?path=beginner` or `?path=advanced` to select a route directly. Run from
this directory with `pnpm dev`; `pnpm build` creates the static browser host.
