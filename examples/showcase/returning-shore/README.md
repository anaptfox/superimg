# Pentimento — The Returning Shore

A dry pigment coast on plaster. Brush impulses move nearby grains; an analytic
four-second decay restores their original positions. This is deterministic
authored material, without collision physics or a stateful simulation loop.

The 24-second 4K film gathers the painting, moves closer, reveals an older
shoreline, repairs the surface, then pulls back to show the panel and its history.
The `teaching` variant adds explanation to the same motion and original score.

The material-studies gallery owns normalized pointer strokes and logical time.
Arrow keys and Space, position sliders, and a preset trace provide equivalent
gestures. Replay records remain immutable; only unexpired impulses enter the
spatial index. Reduced draws 9,545 of 18,000 grains without changing the model.
