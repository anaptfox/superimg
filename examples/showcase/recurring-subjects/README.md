# Recurring subjects

Two distinct mugs share one immutable ceramic design. Across the cut at two
seconds, breakfast's fill changes explicitly while counter remains full.
Placement changes without redefining either subject. The root and exact square
edition sample the same subjects and story clock.

```sh
just cli check examples/showcase/recurring-subjects/recurring-subjects.media.ts
just cli inspect examples/showcase/recurring-subjects/recurring-subjects.media.ts --at 3s --pretty
just cli export examples/showcase/recurring-subjects/recurring-subjects.media.ts --for 640x360.mp4
```

This is a binding/continuity example, not a physical simulation. Revision strings
are explicit author references; the host separately retains source/resources and
decides whether a design is accepted. State and performance are ordinary finite
JSON input, with no hidden playback history.
