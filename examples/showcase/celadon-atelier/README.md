# Atelier, 4 pm

An SVG room with reusable tea props. The three tins share one drawing with different labels and finishes; the two cups share one drawing with different glaze and tea levels. The font is distributed under the accompanying SIL Open Font License.

Install the example's dependencies, then run `npx superimg dev atelier.media.ts` or `npx superimg export atelier.media.ts --for 1600x1000.svg --for 1600x1000.png`.
