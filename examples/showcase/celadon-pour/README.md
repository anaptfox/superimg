# The Pour

One teapot, hand and cup carry a continuous pour across three camera shots. The drawings remain editable SVG files; named parts, placement and anchors use SuperImg's existing Scene tools. The font is distributed under the accompanying SIL Open Font License.

Install the example's dependencies, then run `npx superimg dev pour.media.ts` or `npx superimg export pour.media.ts --for 1280x720.mp4`. The `?superimg-svg` import supplies the SVG bytes to the source compiler.
